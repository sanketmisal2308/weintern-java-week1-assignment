## 📌 Overview

This repository contains the three Java programming assignments completed as part of the WeIntern Java Development Internship — Week 1.

The assignments focus on Java fundamentals, Object-Oriented Programming (OOP), collections, exception handling, user input, and menu-driven console applications.

## 🎯 Objectives

- Understand Java programming fundamentals.
- Apply classes, objects, constructors, and encapsulation.
- Build interactive console-based applications.
- Work with Java Collections Framework.
- Handle invalid inputs and runtime errors.
- Follow proper project organization and documentation practices.

## 🚀 Projects Included

### 1. Library Management System

**Folder:** `library_management_system`

A console-based application for managing library books.

**Features:**
- Add a new book.
- View all books.
- Search books by ID or title.
- Issue and return books.
- Remove books.
- Handle invalid inputs and book operations.

**Technologies:** Java, OOP, ArrayList, Scanner.

**How to run:**

Open the terminal in the `library_management_system/src` folder and execute:

```bash
javac Book.java Library.java Main.java
java Main
```

### 2. Banking Application

**Folder:** `banking_application`

A console-based application that simulates basic banking operations.

**Features:**
- Deposit money.
- Withdraw money.
- Check account balance.
- Validate deposit and withdrawal amounts.
- Handle insufficient balance.
- Handle invalid numeric input and menu choices.

**Technologies:** Java, OOP, Exception Handling, Scanner.

**How to run:**

Open the terminal in the `banking_application/src` folder and execute:

```bash
javac BankAccount.java BankingApp.java Main.java
java Main
```

The application starts with a demonstration balance of Rs. 10,000.

### 3. Java Collections Challenge

**Folder:** `collections_challenge`

A menu-driven application demonstrating the use of Java Collections.

**Features:**

**ArrayList**
- Add, remove, update, and search elements.
- Display all elements.

**HashMap**
- Insert key-value pairs.
- Retrieve and update values.
- Check whether a key exists.
- Display all entries.

**Queue**
- Add elements.
- Remove the front element.
- View the front element using peek.
- Display queue contents.

**Technologies:** Java, ArrayList, HashMap, Queue, Scanner.

**How to run:**

Open the terminal in the `collections_challenge` folder and execute:

```bash
javac Main.java
java Main
```
