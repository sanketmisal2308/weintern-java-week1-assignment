# Java Collections Challenge

## Objective
To practice Java Collections using ArrayList, HashMap, and Queue.

## Features
- ArrayList: Add, remove, update, search, and display elements.
- HashMap: Insert, retrieve, update, check keys, and display entries.
- Queue: Add, remove, view the front element, and display elements.
- Menu-driven console application.
- Handles invalid menu input.

## Technologies
- Java
- ArrayList
- HashMap
- Queue
- Scanner
- VS Code

## Project Structure
```text
collections_challenge/
└── Main.java
```

## How to Run
1. Open the project folder in VS Code.
2. Open the terminal.
3. Run:

```bash
javac Main.java
java Main
```
